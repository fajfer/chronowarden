# Contributing to Chronowarden

> [!NOTE]
> **This file was generated by an AI assistant (Claude Code)** and hasn't been rewritten by the maintainer yet.

Thanks for helping! Bug reports, ideas and pull requests are all welcome.

## Reporting bugs and ideas

Open a [GitHub issue](https://github.com/fajfer/chronowarden/issues) with what you expected, what happened, your
Chronowarden version and your Vault/OpenBao version. Questions are also welcome on
[Matrix](https://matrix.to/#/#chronowarden:reszka.org).

**Security problems go to [SECURITY.md](SECURITY.md), not to public issues.**

## Pull requests

1. Fork the repository and branch from `main`. `main` only accepts pull requests that pass CI.
2. Keep the change focused on one thing, and follow the style of the code around it.
3. **Add tests:** new features need tests, bug fixes need a regression test.
4. Run the checks before pushing:

   ```bash
   uv run black --check .
   uv run ruff check .
   uv run pytest
   cd frontend && npm run check
   ```

5. Write commit messages as [conventional commits](https://www.conventionalcommits.org/) (`fix: ...`,
   `feat: ...`, `docs: ...`), one kind of change per commit.
6. New files carry an SPDX header (`SPDX-FileCopyrightText` and `SPDX-License-Identifier: EUPL-1.2`); look at any
   existing file for the format.

See the [README](README.md) for the development setup (`dev-setup.py` starts local Vault and OpenBao instances).

## AI-assisted contributions

Allowed, if you have read and understood the change. Mark commits with an `Assisted-by: <tool>/<model>` trailer
rather than `Co-authored-by:`, which is for people.
