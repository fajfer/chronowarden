# CycloneDX VEX with every release

- **Status:** approved
- **Date:** 2026-11-07
- **Issue:** none

## Goal

A user who scans a Chronowarden release with a VEX-aware scanner (`trivy sbom --vex`) doesn't see the
vulnerabilities we've analysed as not affecting us, and can read why. Each release carries a CycloneDX VEX document
per SBOM, generated from `vex/chronowarden.vex.cdx.json`; the image ones are attested to the image (ADR-030).

## Non-goals

- OpenVEX or CSAF output (grype users still see the findings; ADR-030 consequences).
- Statements for vulnerabilities that affect us or are fixed: those are fixed by upgrading.
- Scanning in CI. Alerts still come from Dependabot.

## Scope

`vex/`, `scripts/`, `tests/`, `.github/workflows/release.yaml`, `.github/workflows/docker.yaml`, `README.md`,
`.ai/docs/release.md`.
