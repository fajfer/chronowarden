# Release 0.6.2: Vault passthrough removal and hardening

- **Status:** implemented
- **Date:** 2026-10-10
- **Issue:** none (security advisory, published together with the fix)

## Goal

Close the remaining input-handling flaw found by the 0.6.2 security review and harden the defaults, as a patch
release on top of 0.6.1.

## Non-goals

- Anything in 0.7 (systems/owners, SvelteKit 3, dev-setup rework).

## Scope

`chronowarden/api/vault.py`, `frontend/src/lib/api/vaults.ts`, `chronowarden/app.py`, `chronowarden/config.py`,
`pyproject.toml`, `Dockerfile`, `.github/workflows/`, `deploy/kubernetes/deployment.yaml`, `README.md`,
`CHANGELOG.md`, tests, agent docs.

## ADRs affected

None. (ADR-004 metadata-only still holds; these endpoints are removed, not loosened.)
