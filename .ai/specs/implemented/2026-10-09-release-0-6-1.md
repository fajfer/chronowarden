# Release 0.6.1: path traversal fix

- **Status:** implemented
- **Date:** 2026-10-09
- **Issue:** none (security advisory, published together with the fix)

## Goal

The SPA catch-all in `chronowarden/app.py` no longer serves files outside the frontend build directory, and unknown
`/api/...` paths answer 404 instead of the UI page. CI starts the production image and checks it before pushing.

## Non-goals

- Anything else from 0.7.

## Scope

`chronowarden/app.py`, `tests/`, `.github/workflows/docker.yaml`, `CHANGELOG.md`, `pyproject.toml`, `README.md`.
