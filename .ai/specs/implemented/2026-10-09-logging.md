# Logging: timestamps, no probe noise

- **Status:** implemented
- **Date:** 2026-10-09
- **Issue:** #58

## Goal

Every log line has a timestamp, and successful requests to `/api/v1/health` and `/api/v1/ready` don't appear in the
access log. Errors and other requests are logged as today.

## Non-goals

- JSON or structured logging.
- Changing log levels or messages elsewhere.

## Scope

`chronowarden/app.py` (or a new `chronowarden/logging_config.py`), `Dockerfile` (uvicorn flags), tests.

## Load

- [root AGENTS.md](../../../AGENTS.md)
- [core](../../../chronowarden/AGENTS.md)
- [deploy](../../../deploy/AGENTS.md)

None.

## Validation

`uv run pytest`; `uv run uvicorn chronowarden:app` and `curl /api/v1/health` shows no access line.
