# Release 0.6.3: stop sync from deleting custom metadata

- **Status:** implemented
- **Date:** 2026-10-11
- **Issue:** none (found during the 0.7 scope review)

## Goal

Sync writes only Chronowarden's own metadata keys and leaves everything else on a secret untouched, as ADR-004
promises. Released from `main`, so it also ships the SvelteKit 3 upgrade (#79) and the native Docker frontend build.

## Non-goals

- Using Vault's `PATCH` metadata endpoint: it needs the `patch` capability, which the documented policy doesn't
  grant (changing that policy is an Ask First item).
- Restoring metadata that earlier releases deleted: Vault keeps no history of it.

## Scope

`chronowarden/integrations/vault.py`, `tests/test_vault.py`, `chronowarden/integrations/AGENTS.md`, `CHANGELOG.md`,
`pyproject.toml`, `README.md`, `deploy/`.
