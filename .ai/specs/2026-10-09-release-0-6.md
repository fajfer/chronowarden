# Release 0.6 Foundations

- **Status:** approved
- **Date:** 2026-10-09
- **Issue:** milestone [0.6 Foundations](https://github.com/fajfer/chronowarden/milestone/2)

## Goal

A clean, predictable core before the compliance work in 0.7: config is strict and has a single form, severity comes
only from config, sync recovers from disconnected vaults, logs are readable, and instances can set their UI defaults.

## Non-goals

- The dev-setup rework with podman and testcontainers (moved to 0.7; only auto-cleanup is in 0.6).

## Scope

All backend modules, frontend, deploy docs.

## Load

- [root AGENTS.md](../../AGENTS.md)
- this file; then each task's Load only

## ADRs affected

ADR-006 text (legacy cascade level removed by #30).
