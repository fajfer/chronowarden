# Release 0.10: verifiable dependencies and safer defaults

- **Status:** in progress
- **Date:** 2026-11-07
- **Issue:** none

## Goal

0.10 ships what landed after 0.9.0 and adds VEX to every release: SPDX 3.0 SBOMs (ADR-028), CycloneDX VEX per SBOM
(ADR-030), an owner-only database file and a startup warning for unchecked TLS, plus the decisions that shape 1.0
(ADR-016, ADR-029, ADR-027) and the isolated dev environments contributors and agents use.

## Non-goals

- The podman/buildah migration (0.11, ADR-031).
- The webhook allowlist code (ADR-029), the config key review (ADR-016) and the Azure Key Vault provider: later.
