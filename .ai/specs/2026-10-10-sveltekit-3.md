# Upgrade the frontend to SvelteKit 3 and TypeScript 6

- **Status:** implemented (merged via PR)
- **Date:** 2026-10-10
- **Issue:** #79

## Goal

The frontend runs on SvelteKit 3 and TypeScript 6 with unchanged behaviour: same pages, same API calls, same
static build served by FastAPI ([ADR-007](../adr/ADR-007-sveltekit-spa-served-by-fastapi.md)). It lands before the
systems and owners UI (#61).

## Non-goals

- UI changes, new features, or fixing the existing 6 `svelte-check` warnings.
- TypeScript 7 (SvelteKit 3 and `svelte-check` don't support it yet).

## Scope

`frontend/package.json`, `frontend/package-lock.json`, `frontend/svelte.config.js` (removed),
`frontend/vite.config.ts`, `frontend/tsconfig.json`, `frontend/src/**`, `frontend/AGENTS.md`, `CHANGELOG.md`.
